## Fusion automatique des mises à jour Dependabot ; DCO contrôlé sur main

- **Quoi** : un workflow programme la fusion (squash) de chaque PR Dependabot dont toutes
  les versions restent dans la même majeure ; la fusion attend les contrôles exigés sur
  `main`. Le job **DCO** tourne aussi sur `main` et vérifie les commits arrivés par la fusion.
- **Pourquoi** : les mises à jour mineures et correctives, déjà regroupées et testées par la
  CI, attendaient une fusion à la main ; un squash dont le message avait été réécrit est
  arrivé sur `main` sans `Signed-off-by` (#177) sans qu'aucun contrôle ne le voie.
- **Limites** : les versions se lisent dans la description de la PR, sans action tierce (le
  dépôt n'autorise que les actions de GitHub) ; dans le doute (version introuvable, ou
  « from X to Y » de majeures différentes, notes de version comprises), la PR reste à la
  main. Une fusion faite par le jeton du workflow ne relance pas la CI de `main` : les images
  `edge` suivent à la fusion suivante. Le réglage « Allow auto-merge » du dépôt est activé.
- **Fichiers** : `.github/workflows/dependabot.yml`, `.github/workflows/ci.yml`
- **Documentation** : architecture (§ Intégration continue), sécurité (§ Contrôles du dépôt)
- **Commit** : branche `ci/automatisation-fusion`

## Recette automatisée dans la CI

- **Quoi** : nouveau job **Recette** : pile de démonstration construite depuis les sources sur
  une base vierge, données d'exemple chargées par l'API, puis `scripts/recette.py` par
  l'interface (page servie, connexion des trois rôles, jeu de données complet, santé de la
  base et de l'annuaire). Les images `edge` attendent aussi la Recette.
- **Pourquoi** : la recette avant fusion se faisait à la main sur l'AMD, seul point de passage
  de toutes les PR ; elle tourne désormais sur chaque PR, sans intervention. L'AMD reste un
  laboratoire d'essais à la demande.
- **Vérification** : pile montée et recette déroulée sur un poste de développement avant la PR.
- **Fichiers** : `.github/workflows/ci.yml`, `scripts/recette.py`
- **Documentation** : architecture (§ Intégration continue), plan d'action
- **Commit** : branche `ci/recette-ephemere`
