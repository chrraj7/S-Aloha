# 2026-11-24 — File des propositions de la CMDB assistée, côté API (F14 étape 5a-5a, CMA-03)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : la file des propositions de la page Configuration › CMDB assistée.
  - **File** : `GET /api/assisted-cmdb/proposals?perimeter=&task=`, les propositions ouvertes de la
    CMDB assistée sur les CI des périmètres dont l'utilisateur est gestionnaire, les plus
    anciennes d'abord (200), avec le CI, la tâche (déduite du champ), l'avant, l'après, le motif
    et la péremption. Le § 5 de la spécification ne prévoyait pas cette route, que la file de
    l'interface demande ; elle y est ajoutée.
  - **Décision** (CMA-03) : par les routes communes des propositions (OPT-15), toutes les règles
    des CI comprises. Un renommage vers un nom déjà pris dans l'environnement est refusé (409,
    CFG-17) et la proposition reste ouverte.
- **Pourquoi** : 5a-5a de l'étape 5 du chantier F14 (#367) ; l'interface suit (5a-5b).
- **Preuve** : `AssistedCmdbProposalsTests` (file par périmètre et par tâche, avant et après ;
  autre gestionnaire écarté ; renommage contraire à l'unicité refusé et resté ouvert ;
  normalisation acceptée et renommage rejeté sortis de la file ; 404 coupée). Il ne compile pas
  sur `main`.
- **Fichiers** : `backend/Modules/ServiceConfigurationManagement/AssistedCmdb.cs`
- **Documentation** : CMDB assistée (CMA-03 en cours ; § 5)
- **Commit** : #367
