# 2026-11-24 — Réglages du modèle de langage, côté API (F14 étape 4a, OPT-20, OPT-22, OPT-23)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : les réglages du modèle de langage, sur une seule ligne en base comme le SMTP.
  - **Réglages** : activé ou non, emplacement (« Dans le SI » ou « Hébergé hors du SI »),
    adresse http(s) terminée par `/v1`, nom du modèle, clé facultative, délai d'une requête
    (10 à 300 s, 120) et taille maximale d'une réponse (1 à 1 024 Ko, 64).
  - **Routes** : `GET` et `PUT /api/admin/settings/language-model` (Admin).
  - **Emplacement** (OPT-22) : l'adresse se résout à l'enregistrement. Une seule adresse hors
    des plages privées, de bouclage et locales au lien refuse l'emplacement « Dans le SI »
    (400). « Hébergé hors du SI » demande une confirmation explicite, gardée avec son auteur,
    et la réponse le signale pour l'avertissement permanent de la page.
  - **Clé** (OPT-23) : chiffrée par le coffre, jamais renvoyée (`hasKey`). Chaque réglage changé
    est tracé, la clé seulement « modifiée » ou « effacée » (OPT-07).
  - **Lecture par le conteneur** : `GET /internal/language-model` remet les réglages, clé
    déchiffrée, au seul conteneur, la CMDB assistée activée.
  - **Dépendance** : celle de la CMDB assistée suit enfin les réglages (OPT-03).
- **Pourquoi** : sous-partie 4a de l'étape 4 du chantier F14 (#366). Le connecteur dans le
  conteneur (4b), puis l'essai, la trace et la page (4c), suivent.
- **Preuve** : `LanguageModelSettingsTests` (3 tests : enregistrement, clé chiffrée jamais
  renvoyée ni tracée en clair, bornes, Admin seul ; adresse publique refusée dans le SI,
  hébergé refusé sans confirmation puis accepté, adresses de bouclage, privées et ULA dans le
  SI, changement d'emplacement tracé ; lecture interne avec la clé, dépendance de la CMDB
  assistée, 403 coupée). Ils ne compilent pas sur `main`.
- **Fichiers** : `backend/Core/Features/LanguageModel.cs`, `FeatureStatus.cs`,
  `backend/Core/Data/AppDbContext.cs`, migration `LanguageModelSettings`
- **Documentation** : fonctionnalités optionnelles (OPT-20, OPT-22, OPT-23 en cours, § 6), base de
  données, architecture
