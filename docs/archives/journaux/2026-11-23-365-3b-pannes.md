# 2026-11-23 — Pannes probables, côté API (F14 étape 3b, TRI-07, TRI-11)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : l'API garde les pannes probables que le tri assisté lui signale.
  - **Signalement** : `POST /internal/outages`, seconde écriture permise au conteneur après
    les propositions. Un signalement porte les membres du groupe et ce qui les lie (même
    service, même CI relié ou sens proche).
  - **Règles vérifiées par l'API** : un seul périmètre (400, TRI-11), seulement les
    incidents encore ouverts. Le groupe s'identifie par ses membres : un signalement qui
    partage un incident avec un groupe ouvert le met à jour, et deux groupes qui se
    rejoignent n'en font plus qu'un. Sous deux incidents ouverts, ou sur `closed`, il se
    ferme.
  - **Notification** : à la formation du groupe, et à elle seule, les gestionnaires du
    périmètre sont notifiés (SOC-21), sur le plus ancien incident.
  - **Bandeau** : `GET /api/incidents/{id}/triage` sert ce qu'il affiche : nombre
    d'incidents ouverts, depuis quand, lien, membres visibles, parent proposé (le plus
    ancien, ou son parent, INC-16), et si l'utilisateur peut déclarer le parent majeur
    (gestionnaire, INC-13). Le tri coupé, la route n'existe pas (OPT-04).
  - **Lecture** : `GET /internal/incidents/open`, les incidents ouverts page après page avec
    leurs CI reliés, d'où le conteneur reconstruira son index (TRI-06).
- **Pourquoi** : sous-partie 3b de l'étape 3 du chantier F14 (#365), première de ses deux PR.
  Le groupe se calcule dans le conteneur, mais le bandeau et la notification relèvent de
  l'API. Le mainteneur a retenu le 2026-11-23 que le conteneur signale les pannes à l'API, qui
  les garde : le bandeau reste visible conteneur arrêté, et la notification part une seule
  fois. OPT-14 est élargi en conséquence. Le calcul du groupe (TRI-05, TRI-06) suit dans le
  conteneur.
- **Preuve** : `ProbableOutagesTests` (3 tests : panne formée puis grossie, une seule
  notification, bandeau, gestionnaire seul à déclarer majeur, 404 hors périmètre et tri
  coupé, 403 interne ; deux périmètres refusés, lien ou fonctionnalité inconnus refusés,
  groupe fermé sous deux ouverts et sur `closed` ; incidents ouverts paginés avec leurs CI,
  résolus exclus). Ils ne compilent pas sur `main`.
