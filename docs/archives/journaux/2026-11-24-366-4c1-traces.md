# 2026-11-24 — Table et réception des traces du modèle de langage (F14 étape 4c-1, OPT-27)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : la trace de chaque appel au modèle, côté API.
  - **Table** `LanguageModelCalls` : fonctionnalité, tâche, modèle, emplacement, version des
    consignes, empreinte SHA-256 de l'entrée pseudonymisée, durée, issue (valide, non conforme,
    délai, erreur), essais, réponses écartées, motif borné à 500 caractères. Ni l'invite ni la
    réponse : la table n'a pas de colonne pour elles. Index sur la date (purge) et sur
    fonctionnalité et date (compteurs).
  - **Réception** : `POST /internal/language-model/calls`, jeton du conteneur, port interne,
    CMDB assistée activée (403 sinon) ; issue, fonctionnalité ou empreinte inconnues : 400.
- **Pourquoi** : 4c se découpe en quatre PR de dix fichiers au plus ; celle-ci porte la
  migration, fusionnée par le mainteneur. L'essai, les compteurs et la purge à 90 jours suivent
  (4c-2) ; le conteneur remet déjà les traces (4c-3).
- **Preuve** : `LanguageModelTracesTests` (403 coupée, 401 sans jeton, 201, 400 hors bornes,
  champs gardés, pas de colonne pour l'invite ni la réponse). Il ne compile pas sur `main`.
- **Fichiers** : `backend/Core/Features/LanguageModel.cs`, `backend/Core/Data/AppDbContext.cs`,
  migration `LanguageModelCalls`
- **Documentation** : fonctionnalités optionnelles (OPT-27 en cours ; § 6), base de données
