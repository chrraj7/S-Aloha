# 2026-11-23 — Conteneur des fonctionnalités optionnelles (F14 étape 2c, OPT-01, OPT-10)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : premier état du conteneur `features`, projet `features/SAloha.Features` et image
  `ghcr.io/chrraj7/s-aloha-features`. L'hôte n'exécute encore aucune fonctionnalité :
  chacune s'y inscrira comme `IContainerFeature`, avec la clé du catalogue de l'API.
  Chaque appel doit porter le jeton du conteneur (`Features:Token`, 32 caractères au moins,
  comparé en temps constant) ; sans lui, tout répond 401, contrôle de santé compris.
  `GET /health` rend `{ version, features }`, la forme qu'attend le contrôle de l'API
  (OPT-01). Hors développement, le jeton d'exemple de la démonstration fait refuser le
  démarrage, sauf avec `Security:AllowSampleSecrets` (S7). Un jeton absent ou trop court
  est journalisé par le nom du réglage, jamais par sa valeur. Image : port 8080 sur le
  réseau du compose seulement, utilisateur sans privilège.
- **Outillage** : tests du conteneur dans le job « API (.NET) », couverture comprise ;
  dépendances vulnérables des deux projets ; image construite par le job « Images Docker » et
  publiée par `scripts/publier-images.sh` (`edge` à chaque fusion, versions) ; Dependabot
  suit le projet, ses tests et son image.
- **Pourquoi** : sous-partie 2c de l'étape 2 du chantier F14 (#364), découpée en trois :
  le conteneur et la CI (celle-ci), le profil `fonctionnalites` du compose avec le jeton
  d'exemple reconnu par l'API, puis les appels de l'API vers le conteneur (OPT-16).
- **Preuve** : `ContainerHostTests` (4 tests : santé et fonctionnalités déclarées, jeton
  refusé, jeton absent ou trop court, jeton d'exemple refusé hors démonstration), dans un
  projet de tests nouveau. Le contrôle Preuve ne couvre pas encore `features/`. Essai de
  l'image en local : 401 sans jeton, santé rendue avec, démarrage refusé avec le jeton
  d'exemple, accepté en démonstration, utilisateur `app`, jeton absent des journaux.
- **Fichiers** : `features/SAloha.Features/` (projet, hôte, Dockerfile),
  `tests/SAloha.Features.Tests/`, `.github/workflows/ci.yml`, `.github/dependabot.yml`,
  `scripts/publier-images.sh`
- **Documentation** : exploitation (images publiées), architecture (suites de tests),
  CONTRIBUTING (contrôles avant de pousser)
