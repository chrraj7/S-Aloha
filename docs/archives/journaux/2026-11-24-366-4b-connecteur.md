# 2026-11-24 — Connecteur du modèle de langage dans le conteneur (F14 étape 4b, OPT-21 à OPT-25, OPT-28)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : le seul client de modèle de langage du conteneur `features`.
  - **Format** (OPT-21) : `POST {adresse}/chat/completions`, température 0, sortie demandée
    selon le schéma de la tâche (`response_format`) ; un serveur qui la refuse (400, 422)
    reçoit le schéma par les seules consignes, et le connecteur s'en souvient.
  - **Emplacement** (OPT-22) : chaque connexion résout l'hôte ; un modèle déclaré « dans le
    SI » qui se résout hors des plages privées n'est pas appelé. Ni redirection suivie, ni
    mandataire HTTP.
  - **Réglages** (OPT-23) : relus par le port interne à chaque appel, jamais écrits.
  - **Pseudonymisation** (OPT-24) : IP (IPv6 compressée comprise), MAC, noms d'hôte et FQDN,
    comptes `DOMAINE\nom`, courriels, et les valeurs que l'appelant déclare (nom d'un CI,
    numéro de série), remplacés par des jetons stables le temps d'une requête puis rétablis.
  - **Sortie** (OPT-25) : lue comme du JSON, validée contre le schéma de la tâche, sans jeton
    inventé, contrôlée par la tâche (références citées) ; écartée, elle est réessayée une
    fois. Rien n'est exécuté : la sortie n'est qu'une donnée.
  - **Charge** (OPT-28) : une requête au modèle à la fois, délai et taille de réponse bornés
    par les réglages ; une panne, un délai ou une réponse refusée rendent une issue motivée,
    sans rien lever. Chaque appel rend sa trace (fonctionnalité, tâche, modèle, emplacement,
    version des consignes, empreinte SHA-256 de l'entrée pseudonymisée, durée, issue, essais,
    réponses écartées), que l'API recevra avec l'essai (4c).
- **Pourquoi** : sous-partie 4b de l'étape 4 du chantier F14 (#366), après les réglages côté
  API (4a, #392). L'essai, la trace gardée 90 jours et la page suivent (4c).
- **Preuve** : `PseudonymizerTests` (4 tests) et `LanguageModelClientTests` (6 tests) contre un
  serveur d'inférence factice ; ils ne compilent pas sur `main`.
- **Fichiers** : `features/SAloha.Features/LanguageModel/` (`LanguageModelClient.cs`,
  `Pseudonymizer.cs`, `SchemaCheck.cs`), `Host/ApiClient.cs`, `Host/ContainerHost.cs`
- **Documentation** : fonctionnalités optionnelles (OPT-21, OPT-23, OPT-24, OPT-25, OPT-28 ✅ ;
  OPT-22 en cours ; § 7), architecture, plan d'action
