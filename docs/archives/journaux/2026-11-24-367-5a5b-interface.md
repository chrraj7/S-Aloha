# 2026-11-24 — Interface de la CMDB assistée (F14 étape 5a-5b, CMA-01, CMA-03, CMA-04)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : les écrans de la CMDB assistée, la fonctionnalité activée seulement (OPT-04).
  - **Configuration › CMDB assistée** (gestionnaires) : lancer une analyse sur un périmètre géré,
    avec ses tâches (Renommer, Normaliser, Reclasser) ; suivre les analyses (statut, motif d'un
    échec, propositions faites et écartées), relues toutes les 10 secondes tant qu'une est
    active ; la file des propositions, filtrée par tâche, avant et après côte à côte, décidée une
    à une ou par sélection. Accepter relit le CI et passe par sa modification, l'en-tête de la
    proposition joint (OPT-15) : un refus des règles du CI (409 d'un nom déjà pris) s'affiche, et
    la proposition reste à décider. Une proposition périmée ne se choisit pas.
  - **Fiche CI** : l'encadré commun des propositions, « Propositions de la CMDB assistée ».
  - **Paramétrage › Convention de nommage** : une description et des exemples par type de CI ;
    une description vide retire la convention.
- **Pourquoi** : dernière sous-partie de 5a (#367) : l'étape 5a est complète. Suivent 5b (fusion,
  doublons candidats), 5c (relier, criticité, aide au sas) et 5d (mesure, réglages, jeu
  d'essai).
- **Preuve** : `AssistedCmdb.test.jsx` (3 tests : lancement et suivi ; file par sélection, refus
  affiché, proposition périmée non choisie, filtre et rejet ; convention de nommage). Ils
  échouent sur `main`.
- **Fichiers** : `frontend/src/modules/service-configuration-management/pages/AssistedCmdb.jsx`,
  `ConfigurationItemDetail.jsx`, `frontend/src/api.js`, `App.jsx`, `modules/registry.js`,
  `core/components/icons.jsx`
- **Documentation** : CMDB assistée (CMA-01, CMA-03, CMA-04 ✅ ; § 4), plan d'action, note de
  changelog
