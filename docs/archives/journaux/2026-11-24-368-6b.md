# 2026-11-24 — Serveur MCP : conteneur `mcp` et ses six outils de lecture (MCP-01, MCP-02, MCP-05 à MCP-09 ; #368 6b)

<sub>[← Archives](../readme.md)</sub>

- **Quoi** : projet `features/SAloha.Mcp`, sur le SDK C# officiel du protocole
  (`ModelContextProtocol.AspNetCore` 2.4.0, protocole 2026-07-28), transport « Streamable
  HTTP » sur `/mcp`, sans session. Avant le protocole : une origine hors de
  `Cors:AllowedOrigins` reçoit 403 ; une fenêtre de 60 requêtes par minute et par jeton
  (429) ; puis l'API reconnaît le jeton personnel (`GET /api/me/tokens/current`) :
  fonctionnalité coupée 404, jeton refusé 401, annuaire injoignable 503. Six outils, tous
  annotés en lecture seule : `search`, `get_record`, `similar_cases`, `my_work`,
  `ci_impact`, `triage_suggestions`. Ils n'appellent que des routes publiques en `GET`,
  avec le jeton de l'utilisateur ; hors de sa portée, une fiche est « introuvable ». Les
  textes saisis passent sous la clé `userEntered`, que les consignes du serveur désignent
  comme des données ; listes coupées à 20, textes à 2 000 caractères (`truncated`). Une
  ligne de journal par appel d'outil : compte, jeton, outil, résultats, durée, issue.
  `/health` sans jeton déclare `mcp-server`.
- **Ajouts à l'API** (MCP-02 : une donnée qui manque à un outil s'ajoute à l'API) :
  `GET /api/me/tokens/current`, ouverte sans authentification et coupée en 404 avec la
  fonctionnalité, rend le jeton présenté ; la vue d'impact d'un CI rend aussi ses incidents
  et changements ouverts reliés et visibles (`openIncidents`, `openChanges`).
- **Pourquoi** : sous-parties 6b-1 et 6b-2 de #368, réunies en une PR ; 6b-3 (image, compose,
  nginx, CI, Recette), qui touche l'outillage, suit à part. Les tests du conteneur vivent dans
  `tests/SAloha.Features.Tests/Mcp/` : la CI et le contrôle Preuve couvrent déjà ce projet
  pour tout code de `features/`.
- **Preuve** : `McpServerTests` (10 tests, client du SDK contre une API publique factice :
  protocole et 405 sans session, origine, 404, 401, 503, santé, six outils de lecture, jeton
  relayé sur des `GET` publics seulement, introuvable, `userEntered`, 429 par jeton, coupes,
  journal sans jeton ni contenu) ; `PersonalTokensTests.MCP_01_MCP_09_…` (jeton présenté,
  401, 503, 404 coupée, révoqué) ; `ConfigurationImpactTests.MCP_05_…` (ouverts reliés dans
  les deux sens, résolus et clos écartés, autre périmètre caché sauf à l'Admin).
